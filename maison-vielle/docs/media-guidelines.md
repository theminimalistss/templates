# Media guidelines

## Art direction

Warm ivory, pale stone, formal greenery and natural light. Restrained saturation connects the estate, interiors and wedding details. Preserve architectural detail and fabric/flower texture. Never hotlink production stock media. Keep originals in ignored `.cache/media`, never in `public`.

## Rebuilding assets

`npm ci` (Node 22.13+). Install FFmpeg for video; scripts fail clearly when missing. Download originals using the exact verified URLs in `content/media-manifest.json` into `.cache/media` with the recorded `originalFilename` (video uses `filename`). Recheck licensing when changing assets.

```sh
npm run media:images
npm run media:video
npm run media:inspect
# Alternatively point at another raw directory:
MEDIA_SOURCE_DIR=/path/to/originals npm run media:optimize
```

Sharp is a development dependency. Generated AVIF/WebP widths are specific to each use. No upscaling; AVIF quality varies 53–55 and WebP 80–82. `content/media.ts` centralizes dimensions, alt text and source sizes; update it and the manifest together. Scripts remove EXIF. Production CSS adds restrained display saturation.

## Loading and accessibility

Hero is a photograph with eager loading and high fetch priority; it remains visible without JavaScript. When WebGL is available, a spatial version is layered over it using a small depth map (`hero/*-depth.webp`, about 3–5 KiB each, generated by `npm run media:depth`). Regenerate the depth maps whenever the hero image or its mobile crop changes. All below-fold pictures are lazy-loaded with explicit dimensions and responsive `sizes`. Film sources do not exist in the DOM until the dialog is opened. There is no background mobile video transfer. The on-demand film is small enough for mobile, has native controls and a poster, and starts paused under reduced motion. The dialog unmounts the video on close. No unnecessary codec/mobile duplicates are retained.

## Review

Architecture and wedding imagery use a consistent cream/green palette; obvious logos and identifiable faces were excluded. The images deliberately illustrate a fictional venue and should be replaced with genuine venue photography for a real business. Source identities and rights considerations are retained in `media-sources.md`.

## Mobile hero refinement

Portrait art direction avoids serving a wide image only to crop most of it away. 480px and 768px AVIF/WebP variants; 768px AVIF 93.6 KiB. A picture media query selects these only below 768px.
