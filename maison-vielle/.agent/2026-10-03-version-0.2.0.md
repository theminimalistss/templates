# 2026-10-03 — Version 0.2.0 motion, gallery and mobile refinement

## Summary

Version `0.2.0` turns the initial template into a fully animated editorial site and fixes several mobile issues. Version tracking now starts from a project-level `VERSION` file mirrored in `package.json` and `package-lock.json`.

## Changes captured

- **Loading curtain.** The MV monogram waits on a filling line, then an ivory panel lifts with a curved trailing edge and an olive panel follows.
- **Spatial hero.** Offline Depth Anything V2 depth maps drive a WebGL parallax-occlusion shader. The camera follows the cursor, Android tilt and scroll, sweeps in on load and drifts when idle. Motes, warm light, rays, grain and a magnetic scroll badge add ambient life. The hero text does not follow the cursor.
- **Scroll reveals.** Masked line headings, staggered blur-to-sharp text, upward photo unveils and drawn section rules.
- **Cinematic break.** A pinned section: a framed card opens to full-bleed, then "Let the world wait. / This moment is yours." lights word by word, the photo pushes in, and the film button arrives last.
- **Living gallery.** Nine-photo pool, six tiles. One tile pushes in a new photo every 3.8s, matching orientation and pausing on hover, off screen, while filtered or with the lightbox open.
- **Lightbox.** View Transitions morph from tile to lightbox and back, a dark backdrop, and a side glide between photos.
- **Mobile fixes.**
  - The menu now fills the screen; the dialog's `translate` centring was left in place before.
  - Menu links no longer jump back to the top after navigating.
  - The menu closes when widened to desktop.
  - Desktop links appear immediately after a resize.
- **Mobile inquiry.** Bottom sheet with grab handle, drag-to-close, full-width actions and a quieter focus state.
- **Gallery overflow.** The horizontal scrollbar that flashed during next/previous on desktop is gone.

## Deprecated code updated

- `React.FormEvent` → `SubmitEvent` in the inquiry form handler (`components/maison/interactions.tsx`). React's types deprecate `FormEvent`.
- Zod `z.number().int().nonnegative().safe()` → `z.int().nonnegative()` in `lib/connector-errors.mts`. `.safe()` is deprecated and identical to `.int()`. Behaviour was checked: zero and positive safe integers pass; negatives, decimals and 2^53 fail.
- Removed the unused `data-reveal="zoom"` CSS left over from an earlier cinematic-break design.

The TypeScript language service now reports zero `@deprecated` usages across 89 source files.
